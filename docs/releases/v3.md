# Report v3: solx joins the compiler matrix

The report now compares solc and solx on Solidity source alongside Vyper and Fe.
The matrix contains 123 profiles across 64 benchmarks: 7,867 compile attempts,
7,574 successful artifacts, 293 recorded compile failures, and 28,382 measured
scenarios. Fe skips five benchmarks without an implementation.

## solx results

Both solx 0.1.8 profiles compile all 64 benchmarks. Their Solidity source bundles
match the solc 0.8.34 comparison profiles byte for byte. solx embeds a modified
Solidity 0.8.34 frontend; its release, frontend commit, LLVM build, and binary
checksum are separate provenance fields.

Against solc 0.8.34 viaIR with optimizer runs=200, across all 64 benchmarks:

| Profile | Runtime gas | Runtime bytecode | Scenario deployment gas | Compile wall time |
| --- | ---: | ---: | ---: | ---: |
| solx O3 | -10.0% | -16.1% | -9.4% | 2.63× |
| solx Oz | -8.5% | -18.0% | -15.6% | 2.60× |

These are geometric means over 247 matched scenarios for gas and 64 deduplicated
artifacts for bytecode and compilation. The report's headline cards use the
narrower fixed/scale scope: 129 scenarios and 59 artifacts. In that scope O3 uses
8.9% less runtime gas and 16.7% less runtime bytecode; Oz uses 17.8% less runtime
bytecode. Individual workloads can regress.

The shared execution target is Prague. LLVM modes use one worker and disable
automatic size fallback. These small, per-contract compile timings do not
reproduce whole-project parallel build measurements.

## Correctness and reporting fixes

- The full run verifies 192 compiler pairs, including all 128 solx/solc pairs.
  All 494 solx scenario outcomes match expectations, and applicable differential,
  randomized, property, state, return, and log checks pass.
- Test credit now belongs to the compiler pairs actually tested. Untested
  profiles show `not_run`; a gas cache hit is not proof of a property test.
- Gas and behavioral caches include harness source and Foundry identity.
  Generated Solidity bundles also discard deleted imports before rebuilding.
- The factory observer verifies the exact local mock runtime, then hashes the
  verdict. Hashing its raw bytecode hash previously made generated-shard CBOR
  metadata look like a behavioral difference. The fix preserves all 28,382 gas
  measurements exactly while removing those false observer mismatches.
- Yearn V2 log checks use the shared harness capability definition.
- The UI excludes artifacts with observed correctness failures from performance
  comparisons and lists the failures in Reliability. Raw evidence is retained.
  The 20 historical-profile unexpected reverts and 21 Curve alpha/Venom log
  mismatches also occur in the preceding production dataset.
- Same-profile comparisons return ties, filtered reports select available
  defaults, and solx has its own compiler/version/mode controls and scale curves.

## Execution and publication

Foundry shards now have independent projects, compiler caches, and raw outputs.
The worker pool defaults to four jobs and supports one through eight. A serial
versus parallel check reproduced 1,948 overlapping full-matrix records exactly,
plus all 20 records from the isolated ERC20 smoke run. Compiler timings are
collected before these harness jobs.

Rust tests, strict Clippy, frontend regression tests/build, production-policy
tests, and responsive UI checks cover the integration. Production uploads
require a clean master checkout and a full run from that exact merged commit.
